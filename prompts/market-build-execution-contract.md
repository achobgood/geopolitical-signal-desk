# Fortified execution prompt — Signal Desk Market Research and Decisions

**Owner mandate:** Build a functioning investment research system with the strongest observable ideas from Barebone AI's public materials; do not copy private code, scrape restricted sources, or treat competitor marketing as validation. Preserve the original geopolitical Signal Desk and the user's one-platform architecture. The goal is better *measured decisions*, not more pages, agents, or datasets for their own sake.

## Binding execution rules

1. **Evidence before architecture.** For every new capability, identify the provider, entitlement, scope, data shape, timestamps, refresh/failure path, exact calculation, durable storage, and how a skeptical owner can verify it. A missing credential or rate-limited provider must result in an explicit DISABLED / STALE / NO_TRADE state. No fake fixtures, source URLs, historical predictions, or test output in production.
2. **Deterministic finance, AI for interpretation.** Compute RSI, ATR, SMA, confirmed pivot zones, volatility-adjusted stops and sizing from validated numerical data; NEVER ask an LLM to guess a chart level, stock price, return, or statistical win probability. AI may formulate competing theses only with source IDs and original collected times.
3. **Separate layers:** public source capture → validated numeric inputs → math → hypothesis synthesis → security/risk gate → proposal-only ticket → timestamped audit → forward outcome. No automatic brokerage orders, secret leakage, or personal portfolio data in the public research API.
4. **Temporal integrity.** A source's *original date* differs from the time the platform first observed it. A pivot high/low requires subsequent completed bars to be confirmed. A weekly bar must complete before use. Historical backtests must use only observations collected before the simulated decision. A retrospective replay is not a historical alert. No later corrected source/assessment can appear at an earlier cutoff.
5. **Quantitative honesty.** A trend score is not a calibrated probability. Exact entry/stop/target levels are reference-only until the stock quote, position, borrow/earnings/session data and risk controls have actually passed. No trade signals from VIX/VXN alone; those are volatility indices, NOT tradable equity quotes.
6. **No duplicate signal counts.** Capture original provider/canonical source, provider lineage, session, content/version digest and first-seen time. Corrections are append-only. Repeated data/syndication cannot boost conviction.
7. **Forward measurement.** Save issued recommendations and outcome candidates before outcomes occur. Compute later outcomes only from future sessions actually collected, including transactions/slippage assumptions where relevant, and show the full denominator and negative outcomes. Do not turn retrospective demonstrations into predictive accuracy claims.
8. **Fail closed without stonewalling.** If SEC EDGAR requires a genuine contact identity or consolidated price feed requires licensed keys, build and test the disabled and authenticated pathways, mark the live feature blocked, and tell the owner exactly what to provision and what it will unlock. Never invent credentials, substitute single-exchange IEX for SIP, or incur subscription charges without approval.
9. **User experience:** one Signal Desk with geopolitical, market, and *private* trade sections; keep public and owner-only data separated. Do not quietly add a second production frontend. If the current tool cannot edit the existing ChatGPT Site, maintain a tested backend interface, document the single missing integration, and ask the owner for Work mode/site edit permission only when it becomes the blocking item.
10. **Tests must assert real acceptance invariants:** malformed/out-of-order bars rejected; current incomplete candles excluded; rolling indicators and confirmed pivots deterministic; volatility bands scale with ATR; conflicting/missing evidence causes explicit abstention; no stale quote or future lookahead; auth/RLS denies anonymous reads; migration and live API smoke pass; a real collector run produces provenance-backed numeric results.
11. **Delivery:** commit reviewed work to feature branch and PR; run full Python/JavaScript CI; migrate the same existing Supabase project; verify cron receipts, RLS and Render deployed revision; verify an actual API response; preserve geopolitical schedulers and existing Market Desk. Merges only on passing checks. If a safety tool blocks, stop the affected write, report operation and actionable request to owner, and continue independent permitted work.
12. **Status discipline:** classify each subsystem: NOT_CONFIGURED, CODE_TESTED, LIVE_SOURCE_OBSERVED, CLOCK_RUN_VERIFIED, OUTCOME_TRACKED, PREDICTIVE_EDGE_VALIDATED. A green build or good-looking dashboard is *never* a substitute for a higher tier.
